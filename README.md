# AUREUS Crypto Trading Platform

AUREUS is a full-stack cryptocurrency trading platform that enables users to simulate cryptocurrency trading, track portfolio performance, and analyze market trends in real time. The platform integrates live cryptocurrency market data through the CoinGecko API and provides interactive dashboards for portfolio analytics and profit/loss visualization.

## Features

- Secure JWT-based Authentication and Authorization
- Real-Time Cryptocurrency Market Data Integration
- Buy and Sell Cryptocurrency Simulation
- Portfolio Management and Holdings Tracking
- Wallet and Transaction Management
- Watchlist Functionality
- Interactive Dashboards and Analytics
- Real-Time Price Updates
- Profit/Loss Calculation and Visualization
- Responsive User Interface
